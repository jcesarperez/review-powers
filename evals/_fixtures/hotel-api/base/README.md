# hotel-api

Quotes for group bookings: rooms, discounts, and the availability blocks we
send to the hotel's PMS.

## Develop

```bash
npm install
npm test
```

## Tickets

Work is tracked in the `HOT` project. Branch names and PR titles carry the
ticket key (`feat/hot-123-short-name`). Read tickets from the terminal with
the `tracker` CLI (`tracker --help`).
