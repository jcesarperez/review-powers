PASS if the merge problem is illustrated with a concrete example with actual
numbers, such as: "2 Doubles for 3 nights + 1 Double for 1 night → the PMS
gets one block of 3 Doubles × 3 nights = 9 room-nights instead of 7". Any
numbers are fine as long as the example shows the input and the wrong result.

FAIL if the problem is only explained in the abstract ("nights from the first
line are used for all merged lines") with no worked example.
